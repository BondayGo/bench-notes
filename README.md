# bench-notes

Maintenance and debugging notes for the motor test benches. Mostly things
I keep re-looking up: daily checklists, Modbus exception codes, RS-485
wiring traps, motor sizing rules of thumb. Published so coworkers can
grab them without asking me for the file.

Nothing here is confidential — no customer names, no site photos.

## Contents

- [notes/daily-checklist.md](notes/daily-checklist.md) — morning check before a run
- [notes/modbus-quick-ref.md](notes/modbus-quick-ref.md) — exception codes and register maps we use
- [notes/serial-debugging.md](notes/serial-debugging.md) — RS-485 / serial port debugging traps
- [notes/motor-sizing.md](notes/motor-sizing.md) — quick sizing math for bench rigs

## Why markdown

Plain text diffs well and renders on the shop laptop without any tooling.
Diagrams are ASCII on purpose — they survive every editor.
